# FacePointer

FacePointerは、顔の動きだけで操作できるコミュニケーションボード（意思伝達装置）です。
発話や肢体に不自由がある方、失語症などの症状がある方が、視線やまばたき（または特定の顔のジェスチャー）で自分の意思を周囲に伝えることを目的としています。

![App Preview](dist/media/FacePointer.png) <!-- アイコンなどがあればここに配置 -->

## 🌟 主な機能

- **顔トラッキング:** MediaPipe FaceLandmarkerを使用した、高精度かつ低遅延な顔認識。
- **ポインタ操作:** 鼻の向きでマウスカーソル（赤いポインタ）を操作し、ボタンを選択。
- **質問モード（既定）:** 介助者が画面上の質問ボタンを選び、本人が回答パネルを選んで答える。パネルを選ぶとすぐ発話。
- **お話モード:** 用意した会話を「話題 → 内容 → …」と選んで話す。
- **滞留確定:** パネル上で止まると円グラフ状のインジケータが埋まって確定。
- **口ジェスチャー確定:** 口を開くことでホバー中のパネルを確定。
- **最高品質の音声合成:** Google Gemini 2.5 Flash TTS (`Achernar`) に対応。非常に自然で落ち着いた日本語音声で発話をサポート。
- **音声キャッシュ (IndexedDB):** 生成した音声は保存され、2回目以降は瞬時に再生されます。
- **デスクトップアプリ化:** Tauri (Rust) を使用した軽量なWindowsデスクトップアプリとして動作。

## 🚀 インストール & 実行

### 一般ユーザー (実行・インストール)
1. [Releases](https://github.com/ohru131/FacePointer/releases) から最新の `FacePointer_x.x.x_x64_en-US.msi` をダウンロードしてインストールします。
2. または、`FacePointer.exe` を直接実行してください。
3. インストールせずに試す場合は、ブラウザ版 https://ohru131.github.io/FacePointer/ を開きます（カメラの許可が必要）。

### ブラウザ版（GitHub Pages）
- `main` へのpushで `.github/workflows/pages.yml` が `dist/` とMediaPipeモデルをGitHub Pagesへ自動デプロイします（Windowsビルドとは別ジョブで並行実行）。
- 初回のみ、リポジトリの Settings → Pages → Build and deployment の Source を「GitHub Actions」にしてください。
- 設定・学習内容・APIキーはブラウザごとに保存されます（デスクトップ版とは共有しません）。
- 右上の ⛶（⚙ の左）で全画面表示、もう一度押す（または Esc）で解除。その左の ◎ で正面取り直し。どちらもマウスで押すボタンで、ポインタ・滞留では選ばれない。

### 開発者 (ビルド方法)

このプロジェクトを自分でビルドするには、以下の環境が必要です：
- [Node.js](https://nodejs.org/) (v16以上)
- [Rust](https://rust-lang.org/) (Tauriのビルドに必要)

```bash
# 依存関係のインストール
npm install

# 開発用モデルのダウンロード
./download_models.ps1

# 開発モードで実行
npm run tauri dev

# リリースビルド (インストーラーの作成)
npm run tauri build
```

## 🎙 音声合成 (Google Gemini TTS) について
本アプリは **Google Gemini 2.5 Flash TTS** を使用して発話を行います。
初期設定として、画面右上の **⚙（設定）→「音声」タブ** で「Gemini API Key」を入力し、保存してください。

### TTSモデルの選択
提供モデルは順次入れ替わるため、設定画面の **「モデル一覧を取得」** で利用可能なモデルを取得して選べます。
- `Cloud TTS: ja-JP-...` : Google Cloud Text-to-Speech の日本語音声 (既定: `ja-JP-Neural2-B`)
- `Gemini: ...-tts` : Gemini API の TTS モデル。「Gemini 話者」で声 (既定: Zephyr)、「Gemini 口調指示」で話し方 (既定: 明るく、はきはきした女性の声) を変更可

- `ブラウザ内蔵の音声` : 無料・通信なし・遅延なし。前もって作る必要なし（Web版を Edge で開くと「Nanami」など自然な声。デスクトップ版は Windows に入っている日本語の声）
- `VOICEVOX: 話者（スタイル）` : 無料の音声合成ソフト [VOICEVOX](https://voicevox.hiroshiba.jp/) をこのPCで起動して使う。「VOICEVOX」欄の「話者を取得」で一覧に追加
  - Web版・デスクトップ版から使うには、VOICEVOX の設定（`http://127.0.0.1:50021/setting`）の Allow Origin に `https://ohru131.github.io` と `http://tauri.localhost` を追加し、VOICEVOX を再起動（Safari からは使えません。デスクトップ版での接続は実機で要確認）
  - VOICEVOX で作った音声を公開するときは「VOICEVOX:キャラ名」のクレジット表記が必要（設定画面に表示）

取得した一覧はブラウザに保存されます。Cloud TTS / VOICEVOX に変えて保存すると、まだ音声にしていない文の音声を裏で作り始めます（作成中も普通に話せます）。

### 遅延なく話す・オフラインでの利用（重要）
1. 設定 → 音声 の **「音声データを作成」** をクリックします（すぐ作り始め、進み具合と「保存済み ○ / ○ 文」をその場に表示）。
2. パネルを選んですぐ話す文（質問と答え・答えに使うパネル・相づち）のうち、まだ音声にしていない文だけを作り、ブラウザ (IndexedDB) に保存します。お話モードの文は数が多く（パターンによって1000以上）使わないものも多いので前もっては作らず、一度話した文の音声を保存して次からすぐ話します。
3. 保存済みの文は通信なしですぐに再生されます（VOICEVOX の音声も保存されるので、保存済みの文は VOICEVOX を起動していなくても話せます）。**オフライン（病院内などネットがない場所）でも** そのまま使えます。
4. 音声は文ごとに1つ保存し、どのモデル・話者で作ったものも使います。無料枠を使い切ったら別のモデルに変えて「音声データを作成」を押すと、まだ無い文だけを作ります（作成済みの文は作り直さないので、文によって声が混ざります）。声をそろえ直すときは、設定 →「音声」→「音声を消去」で消してから作り直します。
5. ほかの端末へコピーするには、設定 →「音声」の **「書き出し」** で保存した音声を1つのファイル（`audio-cache-日付.fdaudio`）にし、コピー先の端末で **「読み込み」** からそのファイルを選びます（同じ名前の音声は上書き）。ファイルには書き出したときの音声設定（TTSモデル・話者・口調。VOICEVOX は接続先 URL も）が入っていて、読み込むとコピー先もその音声設定に自動で切り替わり、すぐ保存されます。API Key はファイルに入らないので、Cloud TTS・Gemini で新しい文を作るときは、コピー先で API Key を入力してください。

※ APIキーが設定されていない、または通信エラーが発生した場合は、OS標準の日本語音声（Microsoft Nanami等）が自動的に選択されます。

## 🎮 操作モード
質問モード（既定）とお話モードの2つ。設定 → 基本 →「使う画面（モード）」で切り替える（以前の症状モード・シンプルモードは廃止。選んでいた場合は質問モードで始まる）。どちらもパネルを縦横に並べた画面で、ポインタは縦横自由に動かせる。

- **共通のパネル操作:**
  - **グリッドサイズ:** 3×1 / 4×1 / 2×2 / 3×2（既定）/ 3×3 / 4×3 / 4×4。質問モード・お話モードそれぞれの設定タブで選ぶ。3×1・4×1 は横1列で、寝た姿勢などで首を縦に動かしにくい人向け（入りきらなければ横1列のままページ送り）。パネルが少ないときは自動で数を減らして大きく並べる。
  - **ページ送り:** 入りきらない分はパネルの左右の縦長の「◀ 前へ / 次へ ▶」でページ送り（端で反対側へ回り込み）。「次へ」は画面の右端（⛶ ⚙ ◎ の列の下）まで寄せ、空いた幅をパネルに回す。下は「休憩」を横幅いっぱいに置く。
  - **休憩パネル:** 選ぶと休憩中になり、「再開」以外は滞留でも口でも確定しません。再開は通常の2倍（最低2秒）の滞留が必要です（設定 → ポインタと確定 で非表示にできる）。
  - **確定音:** 確定時に短い「ピポッ」を鳴らします（設定 → ポインタと確定 でOFF可）。
  - **滞留(dwell)確定:** パネル上でポインタを止めると円グラフ状のインジケータが埋まり、満タンで確定・発話します。動くとやり直し。時間は設定画面で 0.8〜3.0秒 / OFF（口を開けて確定のみ）から選択（既定 1.5秒）。
  - **再選択防止:** 確定したパネルは、一度別のパネルへ移るまで再確定しません（起動・モード切替直後に乗っているパネルも同様）。
  - 口を開ける確定も併用できます。

- **お話モード:** 事前に用意した会話（`dist/talk-data.js`、約310項目）を「話題 → 内容 → …」と2〜4回選んで話す。
  - 話題: 👋あいさつ / 💗気持ち / ❓聞きたい / 📚マンガ・アニメ（刀剣乱舞・ジブリなど） / 📷思い出・家族 / 🙏お願い・相談
  - どの段でも先頭の「🔊 これで話す」で確定。続きのない言葉（赤）を選ぶとそのまま話す。続きのある言葉は青。「◀ 戻る」「🏠 最初から」で戻る。
  - **👤 相手:** 来ている人（お父さん・お母さん・お姉ちゃん・お兄ちゃん・看護師さん）を選ぶと、文頭に「お母さん、〜」と呼びかけが入り、その人向けの話題も出る。決めなければ呼びかけなし。
  - **😄 相づち:** 「へえ！」「それで？」「わかる！」「あはは」など16種を1回で話す（相手の話に反応する用）。
  - **⭐ よく話す:** 話した文を回数順に出し、選ぶとそのまま話す（この端末内だけに保存、設定で消去可）。
  - あいさつは時間帯（朝・昼・夜）に合うものだけ出る。
  - 設定 →「お話モード」タブで、話題・言葉ごとの表示/非表示（外すとその先も出ない）、文の追加（「✏️ 自分の言葉」に並ぶ。先頭に `{呼}、` で呼び名が入る）。
  - **AIで会話パターンを作る:** 設定 →「お話モード」で本人の性別・年齢を入れ「💬 質問を作る」→ Gemini が家族・介助者向けの質問を出す → 答えて「✨ 会話パターンを作る」。相手（呼び名）と会話の木を生成し、名前と日付を付けて自動保存・使う設定にする（`dist/talk-generator.js`）。
    - 作ったパターンは「会話パターン」の一覧に残り、いつでも切り替え・名前変更・削除できる（初期データは常に残る）。
    - 「回答を引き継ぐ」がONなら、今のパターンを作ったときの回答をもとに追加の質問を出して作り直せる。
    - Gemini APIキー（音声タブ）が必要。モデルは既定 `gemini-flash-latest`（最新の Flash。変更可）。
  - 会話データは `dist/talk-data.js` の `TALK_TREE`（id / label / emoji / say / children 最大5 / for / time）。旧「文づくりモード」はお話モードに置き換えた。
  - **talk studio（ローカルで作って登録）:** `npm run talk:studio` で http://127.0.0.1:5180 を開く。① インタビュー → AI で作成、または「標準をコピー」・アプリで「書き出し」したファイルの読み込み → ② 木の上で文・絵文字・相手・時間帯の修正、追加・削除・並べ替え（自動保存・チェック付き）→ ③ 絵をまとめて作成（20個ずつのシートを分割。主人公は性別・年齢から設定、作り直しの指定可）→ ④「アプリに登録」で `dist/talk-sets/` に書き出し、会話パターン一覧に組み込みで出る。
    - Gemini の APIキーは `.env` から studio のサーバーだけが使う。作りかけ（インタビューの答えを含む）は `scripts/talk-studio/drafts/`（git 対象外）。
    - 登録した内容と絵は git にコミットすると他の端末・公開版にも出る（公開リポジトリでは誰でも見られる）。
- **設定中は停止:** 設定画面を開いている間は、滞留・口開けの確定、自動復帰を止め、ポインタも隠す。

### 質問への返事テンプレート（設定 → 質問モード → 今すぐ質問する）
- **質問モード（設定 → 基本 → 使う画面）:** 画面の上に質問のボタンが並び、介助者がマウスで切り替える。本人は回答パネルで答え、答えても質問モードのまま次の質問に進める。回答の確定表示中でも切り替えられる。上のボタンはポインタの移動範囲・滞留の対象外。
  - 上の質問ボタンは絵文字アイコン付きの同じ大きさのボタンで、左端から並ぶ。年配の介助者でも場所で覚えられるよう、会話中も並び・表示は変わらない（押した質問だけ色が変わる）。答えは質問文の右に出す。
- お話モード中に設定 → 質問モードの「今すぐ質問する」で質問を選ぶと、画面が回答パネルだけに切り替わり、上部に質問文を表示・読み上げ。
- 回答すると発話してお話の画面へ戻る。「✕ やめる」、設定 → 質問モードの「質問を終了して戻る」、90秒放置でも戻る。
- プリセット（既定の並び。8つずつ2段）: 1段目は体のこと＝気分は？／体がつらい？／どこが痛い？／痛さは？／かゆい所は？／暑い？寒い？／体の向きは？／吸引は？、2段目は暮らしと会話＝お世話は？／部屋は？／何がしたい？／知りたい？／わかった？（失語症のため、話が伝わったかの確認）／相づち／気持ちは？／家族のこと？。はい・いいえ（わかった？と重なる）と ほかには？（設定で作った任意パネルだけ）は既定で出さない（設定でチェックすれば出る）。
  - 同じ答えは1つの質問にだけ置く。暑い・寒いは「暑い？寒い？」、吸引・体の向きはそれぞれの質問、もう一度は「わかった？」、体を起こすは「体の向きは？」（頭を上げて）。以前の体調は？・過ごし方は？・誰に会いたい？は、体がつらい？・何がしたい？・家族のこと？にまとめた。基本のパネル（かゆい・痛いなど）も、これらの質問のどれかにある。
  - 体がつらい？＝体の不調（痛い／かゆい／息が苦しい／おなかが張る／口が乾く／眠れない／生理かも。痛い・かゆいは次の質問で詳しく。気分が悪いは「気分は？」）。お世話は？＝体のお世話と身だしなみ（看護師さん呼んで／おむつ／マッサージ／顔・髪・クリーム・爪／女性の方に）。部屋は？＝カーテン閉めて／電気つけて／暗くして／静かにして。何がしたい？＝楽しみと休むこと（寝たい／動画・テレビ／音楽／スマホ／お話／本／鏡／少し休みたい）。知りたい？＝いま何時？／今日のこと／外の様子／今日の予定。相づち＝お話モードの相づち（もう一回・わからないは「わかった？」にあるので除く）＋続きを話して／話題を変えて。気持ちは？＝うれしい／ありがとう／不安／そばにいて／手をにぎって／一人にして／おはよう／おやすみ／また来てね。
  - 🧩 既存パネルを答えにする質問: 体がつらい？・お世話は？・部屋は？・何がしたい？・知りたい？・相づち・気持ちは？（用意したパネル・お話モードの相づちから選んだもの）、家族のこと？（パネルの「家族」グループ）、ほかには？（「任意」グループ）。相づちは介助者が話している間に使うので、切り替えても読み上げない。
- 設定 →「質問モード」タブで、出す質問（質問モードの上のボタン・「今すぐ質問する」共通。後から増えた質問には、まだ知らない質問にだけ既定の非表示を当てる）の選択、回答パネルの数（1画面の最大。答えが少ない質問は自動で減らして大きく並べる）、▲▼ で並べ替え（「おすすめの並びに戻す」で既定の並び・表示に戻す）、「✏️ 答え」→「答えのパネル」で各質問の答えをドラッグで編集（並べ替え・右の候補から追加・✕で外す。候補はその質問の答え・用意したパネル・任意パネル・相づち。「最初の答えに戻す」で元どおり）、質問の読み上げON/OFF、任意の質問の追加（アイコンの絵文字も指定可。答えはパネルから選ぶ／グループ名で丸ごと選ぶ、または1行1つ「絵文字 表示名=発話文」。両方も可）。

### 答えに使うパネル（設定 → 質問モード タブ）
- **用意したパネル:** 基本の16フレーズ（`dist/app.js` の `BASE_PANEL_GROUPS`）と、追加プリセット48種（画像または絵文字付き。`SIMPLE_EXTRA_PRESETS`）。プリセットは「40代女性・未婚、両親と姉・兄が1人ずつ、入院/療養中」を想定し、返事／家族（お母さん・お父さん・お姉ちゃん・お兄ちゃん等）／体調（生理かも・口が乾く等）／ケア・身だしなみ（女性の方に・髪をとかして等）／過ごし方／気持ち／あいさつに分類しています。
- **任意パネルの追加（自分でパネルを作る）:** 表示名・発話文・絵文字・画像（任意）を指定して追加。作ったパネルは編集中の質問の答えの最後に入り、「追加できる答え」の「任意」からほかの質問にも使える。画像は256pxに縮小してブラウザ（localStorage）に保存されます。任意パネルは「追加できる答え」の 🗑 で消せます。
- 保存は「保存して閉じる」で確定。

## 🧰 画面構成
- **初回の案内:** キャリブレーションを一度も保存していないと、起動時に「はじめに、ポインタを顔の動きに合わせます」を出す（手順3つと「キャリブレーションを始める」「あとで」）。「あとで」を押すと、正面固定のときはいつもの起動と同じく正面だけ登録し、相対のときは案内を閉じるだけ。キャリブレーションを保存すると次からは出ない。
- **利用者の画面:** パネルのみを大きく表示。右上に介助者用の丸ボタンが縦に3つ（⛶ 全画面 / ⚙ 設定 / ◎ 正面取り直し）。⚙ を押すと設定画面がすぐ開く。どのモードでもこの列の幅を空けて並べ、ボタンとパネルが重ならない。質問モードでは、横幅の広い画面（1200px より広い）なら上の質問ボタン2段（8つずつ）と質問文の高さをこの3つのボタンにそろえる（1段目＝⛶、2段目＝⚙、質問文＝◎）。それより狭い画面では質問ボタンが幅に合わせて折り返すので、段数が増え、高さはそろわない。
- **設定画面:** 「今すぐ質問する」「キャリブレーションを始める」は、設定を保存して閉じてから実行する。左の分類は「全体の設定」（基本 / ポインタと確定 / 音声）と「画面ごとの中身」（質問モード / お話モード）の2つに分かれ、各タブの先頭にそのタブで決めることを1行で示す。「保存して閉じる」で反映、「キャンセル」「✕」で破棄。ただし ポインタと確定 の感度スライダーは動かした時点で反映・保存され、「キャンセル」「✕」でも元に戻らない。
  - 基本: はじめて使うときの手順（1番目はキャリブレーション。済み/まだの表示と「キャリブレーションを始める」ボタン付き。ほかは各タブへ移るボタン）・使う画面（モード）・アイコンスタイル
  - ポインタと確定: 動かし方（正面固定 / 相対）・止まって確定（滞留）・休憩・確定音・動きの補助（距離補正・吸着・軸ロック・中央補正）・感度（口の開き・鼻位置移動・顔の傾きのスライダーと計測値。動かすとすぐ反映）・キャリブレーション（「キャリブレーションを始める」・離れた位置の計測・校正リセット）
  - 音声: 声の種類（TTSモデル）と試聴 → API Key → VOICEVOX → Gemini 話者・口調（Gemini 以外を選んでいるときは薄く表示）→ 前もって作った音声
  - 質問モード: 1画面のパネルの数 → 今すぐ質問する（お話モード中に回答パネルへ切り替える）→ 出す質問 → 答えのパネル → 追加できる答え → 自分でパネルを作る → 質問を追加 → 質問の読み上げ
  - お話モード: 1画面のパネルの数 → 会話パターン → 表示する言葉 → 文を追加 → よく話す → AIで会話パターンを作る
